# TV FULL PRO — Eventos deportivos

Este repositorio público almacena **exclusivamente programación y banners propios**.

- La APK descarga `eventos.json`, selecciona eventos vigentes y busca el canal **en las listas IPTV del usuario**.
- No se publican listas, enlaces de reproducción, usuarios, contraseñas ni tokens.
- Los eventos manuales se administran en `config/manuales.json`.
- La agenda deportiva pública de Olé puede incorporarse mediante un extractor programado; sus datos son informativos y no garantizan la disponibilidad de señales.
- **No se compila ninguna APK al actualizar esta programación.**

Enlace público: https://raw.githubusercontent.com/luchochavezfacebook-byte/TVFULL-EVENTOS/main/eventos.json

Las imágenes son propias/autorizadas. No copiar fotografías de Olé sin permiso.
